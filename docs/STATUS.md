## Change log (newest first)
- **10-02, calls can press phone-menu keys:** the call AI now listens first (`firstMessageMode: assistant-waits-for-user`) instead of talking over a recorded greeting, and has Vapi's `dtmf` tool. The prompt (`greetingRule()` in `server/voice.mjs`) lets it press only the key that reaches reservations, the host or staff. It never enters card, phone, account or extension digits. It doesn't leave voicemail, and after two failed tries or a "reservations closed" recording it notes what the recording said and hangs up. The AI disclosure is now its required first words once a person speaks. Max call length went from 180 to 240 seconds. Vapi accepted the config (a test assistant was created and deleted, with no call placed). Not yet tested on a live menu.
- **10-02, call results say why:** after a call, Rall-e only knew an outcome ("needs_guest"), so members got "I don't know why". The structured output (now `Rall-e reservation result v2`; v1 still accepted) adds `reason`, `restaurant_said` (closest verbatim quote), `offered_times` and `how_to_book`. If those are empty, the last restaurant lines from the transcript are quoted instead (long digit runs scrubbed). The details go into the result text and the new `voice_calls.details` column, and the agent prompt says to pass the quote along. Funke example: its automated greeting says phone reservations are noon–5:30 PM Mon–Sat, press 1 for a reservationist; the caller cannot press menu keys yet.
- **10-02, restaurant-call request fix:** members' clear requests were being refused ("Call Funke", "Call cure", "Call again", and a long "call cure and see if… table"), because the explicit-request check only accepted "call" followed within 60 characters by words like them/restaurant/table. Now any request to call counts (venue names, "again", a plain "yes" right after Rall-e offered to call), while "don't call", "I'll call them", "call me" and phone-number questions still don't. The refusal message no longer tells the agent to mention a system step. `callAuthorized()` in `server/voice.mjs`, with tests. Announced to members via what's new.
